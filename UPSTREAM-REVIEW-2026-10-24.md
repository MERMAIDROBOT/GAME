# Upstream review: October 17–24, 2026

The executable `review-upstreams` command retrieves bounded public repository metadata, commits and releases. It records unavailable sources and truncated pagination, and does not install updates or declare source qualified. Repository creation time is not launch evidence.

- [PS2Recomp GIF fix](https://github.com/ran-j/PS2Recomp/commit/e5636981a1c9de368f6b71e819c3dc188dfedbf4): FLG=3 must follow IMAGE handling. The independent bounded GIF inspector carries this case with regression tests. The complete runtime is not blindly rebased.
- [Celosia](https://github.com/HenryKun55/celosia/commit/72b6c633391bd98a5d73348822a7e2c9e863af3d): native-sized presentation avoids an unnecessary readback/downsample path. Its game-specific implementation is not imported or assumed valid for other titles.
- [ps2-web-recomp](https://github.com/snuri00/ps2-web-recomp): recent VU conditional-branch operand-delay work illustrates why delayed operands and JR/JALR require separate contracts. Retain explicit ELF-bound entry discovery rather than copying runtime addresses.
- [Urban Reign v1.4.0](https://github.com/thiagordsfx/urban-reign-recomp/releases/tag/v1.4.0): recent Linux packaging and launcher work is reference material, not evidence of local compatibility.
- [Azkaban](https://github.com/chaikosh/azkaban-recomp), created October 19 UTC: resource-limit negotiation and content-keyed texture caches are useful design references. No game source is imported.
- [Raylib](https://github.com/raysan5/raylib): audio bounds and texture handling updates need focused regression tests before dependency changes.
- [ps2-native-gs](https://github.com/SirBraga/ps2-native-gs) and [MoltenVK](https://github.com/KhronosGroup/MoltenVK): no commits were observed in this review window; do not describe them as new releases.
- [PS2RC](https://github.com/SandstoneDev/PS2RC): source availability does not establish redistribution permission. No implementation is imported.

Public metadata is discovery evidence. Local component fixtures, builds and title acceptance are separate evidence. Never publish disc data, generated retail code or private captures with these tool updates.
