# Keyboard and mouse controls

Click the game window to give it keyboard focus. The guide is visible by default.
F1 hides or restores it; on some Mac keyboards use Fn + F1.

| PS2 control | Keyboard / mouse |
| --- | --- |
| Start | Enter |
| Select | Tab |
| Cross (×) | Space, X, or left mouse button |
| Circle (○) | Escape, C, or right mouse button |
| Square (□) | Z |
| Triangle (△) | V |
| L1 / R1 | Q / E |
| L2 / R2 | Left Shift / Right Shift |
| D-pad | Arrow keys |
| Left analog stick | WASD |
| Right analog stick | I up, K down, J left, L right |

WASD sends only analog-stick movement; arrows send only D-pad buttons.
In menus, use arrow keys to choose an item and Cross to confirm. Circle goes
back. Enter sends the game's Start button, which commonly opens its pause menu.
Escape sends Circle; close the window to quit the app.

During the game's tutorial, translate the displayed controller button using
the table. For example, “tap Triangle to stand” means tap V. Keyboard stick
input is fully pressed or released, so steering is less gradual than an analog
controller. Mouse movement does not control the sticks or camera.

A detected gamepad currently takes precedence over keyboard and mouse input.
L3/R3 stick clicks are not mapped to keyboard keys yet.

## Kelly Slater: Wave House tutorial

1. Use Left/Right or A/D to turn toward the wave icon.
2. Hold Up or W to paddle.
3. As the wave lifts the surfer, tap **V (Triangle)** to stand up.
4. Use Left/Right or A/D to steer while riding.
5. When “Press Start for next instruction” appears, press Enter.

Space or X confirms Continue prompts. Wait for loading screens and tutorial
prompts to finish before sending the next action. F1 hides or restores the guide.

The installed Debug app and a separate GPU Test candidate can use different
runtimes. Performance and playability results apply only to the tested build;
the engineering plan records the current acceptance status.
